# 本地中文 TTS 选型实测（Windows / 免显卡 / 离线）

这是一份在 Windows 上跑通「开源免费、本地离线」中文语音合成的实测选型：不需要显卡、不依赖云端 API，直接告诉你哪些引擎中文能打、哪些不行（Kokoro 系全不对），以及音色/语速怎么调最自然（edge-tts 云希 +15% 语速）。适合给 AI 助手、视频配音、播客做本地语音输出。

A battle-tested guide to free, offline Chinese text-to-speech on Windows — no GPU, no cloud API. It records which engines actually work for Mandarin (Kokoro fails across the board) and the voice/speed settings that sound natural (edge-tts Yunxi at +15% speed). Great for AI assistants, video dubbing and podcasts.
